# Punto 6: Procesamiento de Sonidos y Base de Datos

**Alumna:** Luciana Belén Garay  
**Institución:** INCADE - Dinámica de Sistemas  

##  Consigna del Proyecto:
- **6.a.** Crear una tabla en una base de datos con comentarios de productos (`Producto`, `Like`, `Dislike`, `Cliente`).
- **6.b.** Crear una aplicación que procese audios de comentarios y almacene en la base de datos el análisis de los audios.

##  Componentes Técnicos:
- **`sonido_app.py`**: Backend en Flask con base de datos SQLite (`comentarios_sonido.db`).
- **`sonido_panel.html`**: Interfaz moderna en Tailwind CSS para simular el análisis de audios y visualizar los registros en tiempo real.
