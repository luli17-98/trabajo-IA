##  Consigna del Proyecto:
- **8.a.** Crear una tabla en una base de datos con comentarios de PDF (nombre archivo y resumen).
- **8.b.** Crear una aplicación que procese los PDF y almacene en la base de datos el análisis de los PDF.

##  Componentes Técnicos:
- **`pdf_app.py`**: Backend en Flask con base de datos SQLite (`analisis_pdf.db`).
- **`pdf_panel.html`**: Interfaz moderna en Tailwind CSS para procesar documentos PDF y listar resúmenes en tiempo real.
