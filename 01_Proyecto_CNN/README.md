**Alumna:** Luciana Belén Garay  
**Institución:** INCADE - Dinámica de Sistemas  

##  Consigna / Prompt del Módulo:
> Desarrollar un módulo individual e independiente basado en Redes Neuronales Convolucionales (CNN) para la clasificación y detección de imágenes en el frontend, permitiendo cargar archivos locales, visualizar vistas pretendidas y mostrar análisis detallados con probabilidades de confianza (personas, objetos y entorno).

##  Componentes:
- **`cnn.html`**: Interfaz visual interactiva con Tailwind CSS y selectores de archivos.
- **Lógica de Detección:** Simulación de MobileNetV2 con desglose de clases, barras de progreso y coordenadas.
