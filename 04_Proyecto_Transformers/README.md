##  Consigna / Prompt del Módulo:
> Desarrollar un módulo interactivo para simular la generación de texto autoregresivo utilizando la Arquitectura Transformer, incluyendo un área de prompt, procesamiento de embeddings y visualización del mecanismo Multi-Head Attention.

##  Componentes:
- **`transformers.html`**: Panel interactivo con consola de prompt, respuestas estructuradas y métricas de atención.
- **`transformers_app.py`**: Servidor Python/Flask para la gestión del modelo.
- **Arquitectura:** Atenciones ponderadas por matriz (Query, Key, Value) y generación token por token.
