# Punto 7: Procesamiento de Textos y Base de Datos

**Alumna:** Luciana Belén Garay

##  Consigna del Proyecto:
- **7.a.** Crear una tabla en una base de datos con comentarios de productos (`Producto`, `Like`, `Dislike`, `Cliente`).
- **7.b.** Crear una aplicación que procese textos de comentarios y almacene en la base de datos el análisis de los textos.

##  Componentes Técnicos:
- **`texto_app.py`**: Backend en Flask con base de datos SQLite (`comentarios_texto.db`).
- **`texto_panel.html`**: Interfaz moderna en Tailwind CSS para procesar textos de comentarios y listar registros en tiempo real.
